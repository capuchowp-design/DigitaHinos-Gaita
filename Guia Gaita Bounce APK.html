DigitaHinos Gaita: do GitHub ao APKPure

Mesmo processo do Clarinet Bounce: você já tem a chave de assinatura e já sabe usar o Codespaces. Arquivos grandes (index.html e imagens) chegaram como anexos; os textos curtos estão aqui com botão Copiar.

Suposições (confira antes de começar). Repositório gaitabounce no usuário capuchowp. Pacote io.github.capuchowp.gaitabounce; o pacote não muda depois de publicado. Reaproveitei a mesma chave do Clarinet Bounce (mesmos 3 Secrets). Usar a mesma chave em vários apps é permitido. Link da política: https://capuchowp.github.io/gaitabounce/privacy.html. Se o usuário ou o nome do repositório forem outros, ajuste capacitor.config.json e privacy.html.

Checklist na ordem

  1. Repositório. Abra o repositório gaitabounce no GitHub. Em Settings › Pages, publique o branch main, pasta / (root).
  2. Subir os anexos. Extraia gaitabounce-arquivos.zip no app Arquivos. No repositório: Add file › Upload files e escolha tudo: index.html, sw.js, privacy.html, capacitor.config.json, package.json, version.txt, icon-foreground.png e icon-background.png. Commit.
  3. Criar 4 arquivos por colagem (seção abaixo): Add file › Create new file, digite o nome exato (as barras criam as pastas), cole e faça Commit. Ordem: .gitignore, .github/workflows/build-apk.yml, scripts/prepare_web.py, scripts/android_setup.py.
  4. Cadastrar os 3 Secrets neste repositório (Settings › Secrets and variables › Actions). Copie os valores do repositório do Clarinet Bounce (ou do que você usou lá): KEYSTORE_BASE64 (o texto do release.keystore.b64), KEYSTORE_PASSWORD (sua senha) e KEY_ALIAS (o mesmo alias que você usou ao criar a chave). Se você não tem mais o texto base64 copiado, veja o quadro "Recuperar o texto da chave".
  5. Gerar o APK: Actions › Gerar APK assinado › Run workflow. Baixe o APK em Releases (rascunho) e o sign-report.txt.
  6. Conferir a assinatura: a linha Signer #1 certificate SHA-256 digest deve ser igual à do APK do Clarinet Bounce (mesma chave).
  7. Instalar e testar (lista abaixo), tirar de 2 a 4 capturas e enviar ao APKPure.
Recuperar o texto da chave. Se precisar, abra o Codespace onde você criou a chave (ou o do repositório clarinetbounce), rode base64 -w 0 release.keystore > release.keystore.b64 e depois code release.keystore.b64. Se a chave não estiver mais lá, use o release.keystore que você baixou: envie-o para o Codespace (arrastando para a lista de arquivos) e rode o mesmo comando. Nunca envie esse arquivo ao repositório.

.github/workflows/build-apk.yml
name: Gerar APK assinado

on:
  workflow_dispatch:

permissions:
  contents: write

jobs:
  build:
    runs-on: ubuntu-latest
    timeout-minutes: 45
    env:
      KEYSTORE_BASE64: ${{ secrets.KEYSTORE_BASE64 }}
      KEYSTORE_PASSWORD: ${{ secrets.KEYSTORE_PASSWORD }}
      KEY_ALIAS: ${{ secrets.KEY_ALIAS }}
    steps:
      - name: Baixar o código
        uses: actions/checkout@v4

      - name: Conferir os 3 Secrets
        run: |
          ok=1
          for v in KEYSTORE_BASE64 KEYSTORE_PASSWORD KEY_ALIAS; do
            if [ -z "${!v}" ]; then echo "::error::Falta o Secret $v (Settings > Secrets and variables > Actions)"; ok=0; fi
          done
          [ "$ok" = "1" ] || exit 1

      - name: Instalar Node
        uses: actions/setup-node@v4
        with:
          node-version: 22

      - name: Instalar Java
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 21

      - name: Instalar Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Instalar dependências
        run: |
          npm install --no-audit --no-fund
          python -m pip install pillow

      - name: Montar o app (www)
        run: python scripts/prepare_web.py

      - name: Criar o projeto Android
        run: |
          npx cap add android
          npx cap sync android

      - name: Ajustar versão, ícones e tela de abertura
        run: python scripts/android_setup.py

      - name: Compilar (release)
        working-directory: android
        run: ./gradlew assembleRelease --no-daemon

      - name: Alinhar e assinar com a sua chave
        run: |
          set -e
          source version.txt
          BT=$(ls -d "$ANDROID_HOME"/build-tools/* | sort -V | tail -1)
          echo "Build-tools: $BT"
          echo "$KEYSTORE_BASE64" | base64 -d > "$RUNNER_TEMP/release.keystore"
          UNSIGNED=$(ls android/app/build/outputs/apk/release/*.apk | head -1)
          OUT="DigitaHinosGaita-${VERSION_NAME}-${VERSION_CODE}.apk"
          "$BT/zipalign" -p -f 4 "$UNSIGNED" aligned.apk
          "$BT/apksigner" sign --ks "$RUNNER_TEMP/release.keystore" --ks-key-alias "$KEY_ALIAS" \
            --ks-pass env:KEYSTORE_PASSWORD --key-pass env:KEYSTORE_PASSWORD --out "$OUT" aligned.apk
          "$BT/apksigner" verify --verbose --print-certs "$OUT" | tee sign-report.txt
          echo "---- Impressão digital (SHA-256) da chave no arquivo da chave ----" | tee -a sign-report.txt
          keytool -list -v -keystore "$RUNNER_TEMP/release.keystore" -alias "$KEY_ALIAS" -storepass "$KEYSTORE_PASSWORD" | grep -E "SHA256|SHA-256" | tee -a sign-report.txt
          echo "---- Pacote ----" | tee -a sign-report.txt
          "$BT/aapt" dump badging "$OUT" | grep -E "^package:|sdkVersion|targetSdkVersion|uses-permission" | tee -a sign-report.txt || true
          rm -f "$RUNNER_TEMP/release.keystore" aligned.apk
          echo "APK_FILE=$OUT" >> "$GITHUB_ENV"

      - name: Guardar o APK (aba Actions > Artifacts)
        uses: actions/upload-artifact@v4
        with:
          name: DigitaHinosGaita-apk
          path: |
            DigitaHinosGaita-*.apk
            sign-report.txt
          retention-days: 30

      - name: Criar rascunho de Release com o APK (download direto no celular)
        continue-on-error: true
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          source version.txt
          gh release create "apk-${VERSION_NAME}-build${GITHUB_RUN_NUMBER}" "$APK_FILE" sign-report.txt \
            --draft --title "DigitaHinos Gaita ${VERSION_NAME} (build ${GITHUB_RUN_NUMBER})" \
            --notes "APK assinado. Confira sign-report.txt."
scripts/prepare_web.py
#!/usr/bin/env python3
"""Monta a pasta www/ (o app que vai dentro do APK) a partir dos arquivos do repositório.

- Copia index.html, manifest.json, privacy.html e os ícones (NÃO copia sw.js: no APK não precisa).
- Se as bibliotecas estiverem instaladas (npm install), usa Tone.js e a fonte Inter LOCAIS (funciona offline).
  Se não estiverem, mantém os links da internet que já estão no index.html.
- Esconde o botão PIX no APK (defina SHOW_PIX=1 para mostrar).
"""
import glob, os, re, shutil, sys

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
WWW = os.path.join(ROOT, "www")
VENDOR = os.path.join(WWW, "vendor")

if os.path.isdir(WWW):
    shutil.rmtree(WWW)
os.makedirs(VENDOR)

for name in ["index.html", "manifest.json", "privacy.html"]:
    src = os.path.join(ROOT, name)
    if os.path.exists(src):
        shutil.copy(src, WWW)
for f in glob.glob(os.path.join(ROOT, "*.png")):
    shutil.copy(f, WWW)

index_path = os.path.join(WWW, "index.html")
html = open(index_path, encoding="utf-8").read()

# 1) Tone.js local
tone_src = os.path.join(ROOT, "node_modules", "tone", "build", "Tone.js")
tone_tag = '<script src="https://cdnjs.cloudflare.com/ajax/libs/tone/14.8.49/Tone.js"></script>'
if os.path.exists(tone_src) and tone_tag in html:
    shutil.copy(tone_src, os.path.join(VENDOR, "Tone.js"))
    html = html.replace(tone_tag, '<script src="vendor/Tone.js"></script>')
    print("Tone.js: local")
else:
    print("AVISO: Tone.js local não encontrado; usando o link da internet.")

# 2) Fonte Inter local
font_files = glob.glob(os.path.join(ROOT, "node_modules", "@fontsource-variable", "inter", "files", "inter-latin-wght-normal.woff2"))
import_line = "@import url('https://cdn.jsdelivr.net/fontsource/fonts/inter@5/latin.css');"
if font_files and import_line in html:
    shutil.copy(font_files[0], os.path.join(VENDOR, "inter-latin-wght-normal.woff2"))
    face = ("@font-face{font-family:'Inter';font-style:normal;font-weight:100 900;font-display:swap;"
            "src:url('vendor/inter-latin-wght-normal.woff2') format('woff2');}")
    html = html.replace(import_line, face)
    print("Inter: local")
else:
    print("AVISO: fonte Inter local não encontrada; usando o link da internet.")

# 3) PIX escondido no APK
if os.environ.get("SHOW_PIX") != "1":
    style = "<style>#btnPix{display:none!important}</style>"
    assert "</head>" in html
    html = html.replace("</head>", style + "\n</head>", 1)
    print("Botão PIX: escondido no APK")

open(index_path, "w", encoding="utf-8").write(html)
print("www pronto:", sorted(os.listdir(WWW)))
scripts/android_setup.py
#!/usr/bin/env python3
"""Ajusta o projeto Android gerado pelo Capacitor (rodar depois de `npx cap add android` e `npx cap sync`).

Faz: versão do app, ícones (a partir de icon-512x512.png, icon-foreground.png e icon-background.png), tela de abertura própria (sem logo de terceiros).
"""
import glob, os, re, sys
from PIL import Image, ImageDraw

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
ANDROID = os.path.join(ROOT, "android")
RES = os.path.join(ANDROID, "app", "src", "main", "res")
BG_PNG = os.path.join(ROOT, "icon-background.png")
if os.path.exists(BG_PNG):
    _bg = Image.open(BG_PNG).convert("RGB")
    _c = _bg.resize((1, 1), Image.LANCZOS).getpixel((0, 0))
else:
    _bg, _c = None, (247, 190, 40)
GOLD = (_c[0], _c[1], _c[2], 255)
GOLD_HEX = "#%02X%02X%02X" % _c

def die(msg):
    print("ERRO:", msg)
    sys.exit(1)

# ---------- versão ----------
ver = {}
for line in open(os.path.join(ROOT, "version.txt"), encoding="utf-8"):
    if "=" in line:
        k, v = line.strip().split("=", 1)
        ver[k.strip()] = v.strip()
name, code = ver.get("VERSION_NAME"), ver.get("VERSION_CODE")
if not name or not code or not code.isdigit():
    die("version.txt precisa ter VERSION_NAME=1.0.0 e VERSION_CODE=1 (número inteiro)")
gradle = os.path.join(ANDROID, "app", "build.gradle")
if not os.path.exists(gradle):
    die("android/app/build.gradle não encontrado")
g = open(gradle, encoding="utf-8").read()
g, n1 = re.subn(r"versionCode\s+\d+", "versionCode " + code, g)
g, n2 = re.subn(r'versionName\s+"[^"]*"', 'versionName "' + name + '"', g)
if n1 != 1 or n2 != 1:
    die("não consegui trocar versionCode/versionName no build.gradle (%d/%d)" % (n1, n2))
open(gradle, "w", encoding="utf-8").write(g)
print("Versão:", name, "(código %s)" % code)

# ---------- ícones ----------
icon = Image.open(os.path.join(ROOT, "icon-512x512.png")).convert("RGBA")
fg = Image.open(os.path.join(ROOT, "icon-foreground.png")).convert("RGBA")
legacy = {"mdpi": 48, "hdpi": 72, "xhdpi": 96, "xxhdpi": 144, "xxxhdpi": 192}
adaptive = {"mdpi": 108, "hdpi": 162, "xhdpi": 216, "xxhdpi": 324, "xxxhdpi": 432}

def circle(im):
    mask = Image.new("L", im.size, 0)
    ImageDraw.Draw(mask).ellipse((0, 0, im.size[0] - 1, im.size[1] - 1), fill=255)
    out = Image.new("RGBA", im.size, (0, 0, 0, 0))
    out.paste(im, (0, 0), mask)
    return out

for dens, px in legacy.items():
    d = os.path.join(RES, "mipmap-" + dens)
    os.makedirs(d, exist_ok=True)
    sq = icon.resize((px, px), Image.LANCZOS)
    sq.save(os.path.join(d, "ic_launcher.png"), optimize=True)
    # redondo: fundo dourado cheio recortado em círculo
    full = _bg.resize((px, px), Image.LANCZOS).convert("RGBA") if _bg else Image.new("RGBA", (px, px), GOLD)
    full.alpha_composite(fg.resize((px, px), Image.LANCZOS))
    circle(full).save(os.path.join(d, "ic_launcher_round.png"), optimize=True)
for dens, px in adaptive.items():
    d = os.path.join(RES, "mipmap-" + dens)
    os.makedirs(d, exist_ok=True)
    fg.resize((px, px), Image.LANCZOS).save(os.path.join(d, "ic_launcher_foreground.png"), optimize=True)

if _bg:
    for dens, px in adaptive.items():
        _bg.resize((px, px), Image.LANCZOS).save(os.path.join(RES, "mipmap-" + dens, "ic_launcher_background.png"), optimize=True)
os.makedirs(os.path.join(RES, "values"), exist_ok=True)
open(os.path.join(RES, "values", "ic_launcher_background.xml"), "w", encoding="utf-8").write(
    '<?xml version="1.0" encoding="utf-8"?>\n<resources>\n    <color name="ic_launcher_background">%s</color>\n</resources>\n' % GOLD_HEX)
bg_line = ('    <background android:drawable="@mipmap/ic_launcher_background"/>\n' if _bg
           else '    <background android:drawable="@color/ic_launcher_background"/>\n')
adaptive_xml = ('<?xml version="1.0" encoding="utf-8"?>\n'
                '<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">\n'
                + bg_line +
                '    <foreground android:drawable="@mipmap/ic_launcher_foreground"/>\n'
                '</adaptive-icon>\n')
d = os.path.join(RES, "mipmap-anydpi-v26")
os.makedirs(d, exist_ok=True)
for fn in ("ic_launcher.xml", "ic_launcher_round.xml"):
    open(os.path.join(d, fn), "w", encoding="utf-8").write(adaptive_xml)
# remove o ícone vetorial padrão do modelo (se existir) para não conflitar
for stale in glob.glob(os.path.join(RES, "drawable*", "ic_launcher_foreground.xml")):
    os.remove(stale)
for stale in glob.glob(os.path.join(RES, "drawable*", "ic_launcher_background.xml")):
    os.remove(stale)
print("Ícones: ok")

# ---------- tela de abertura (substitui a imagem padrão do modelo) ----------
splashes = glob.glob(os.path.join(RES, "drawable*", "splash*.png"))
for f in splashes:
    w, h = Image.open(f).size
    canvas = Image.new("RGBA", (w, h), GOLD)
    side = int(min(w, h) * 0.42)
    logo = icon.resize((side, side), Image.LANCZOS)
    canvas.alpha_composite(logo, ((w - side) // 2, (h - side) // 2))
    canvas.convert("RGB").save(f, optimize=True)
print("Tela de abertura: %d imagem(ns) trocada(s)" % len(splashes))
styles = os.path.join(RES, "values", "styles.xml")
if os.path.exists(styles):
    s = open(styles, encoding="utf-8").read()
    s2 = s.replace("@drawable/splash", "@color/ic_launcher_background")
    if s2 != s:
        open(styles, "w", encoding="utf-8").write(s2)
        print("styles.xml: fundo da abertura trocado")
print("Pronto.")

Instalar e testar no celular

  • Ícone branco com a gaita azul e tela de abertura sem logos de terceiros.
  • Tela inicial sem o botão PIX (escondido no APK) e com os créditos.
  • Gire o celular: os botões da tela inicial continuam visíveis.
  • Carregar MIDI: o seletor mostra seus arquivos .mid. Play toca; o selo mostra "Gaita" (gravações) ou "Sintetizador".
  • Com um MIDI carregado, o furo da nota acende com seta de soprar/aspirar; toque no número menor no canto para trocar de posição.
  • Em Partitura, componha algumas notas e toque em ⬇ Salvar e teste as quatro opções (Partitura PDF, Áudio WAV, JSON e MIDI): cada uma deve abrir a janela de compartilhar do Android. Salve em Arquivos e abra cada arquivo.

DigitaHinos Gaita é um visualizador MIDI para gaita de boca diatônica de 10 furos (afinação Richter em Dó). Abra um arquivo MIDI ou componha a sua própria partitura e veja, nota por nota, em qual furo tocar e se é soprando ou aspirando.

O QUE VOCÊ PODE FAZER
• Abrir arquivos MIDI (.mid) e acompanhar a gaita tocando, com o furo aceso e a seta de soprar (↑) ou aspirar (↓).
• Ver bends (½, 1 e 1½ tom), overblows e overdraws quando a nota precisar deles.
• Trocar a posição de uma nota quando ela existe em mais de um furo.
• Cobrir de Dó4 a Dó7, todas as notas cromáticas.
• Compor com até 8 vozes, inserir acordes e usar articulações e ligaduras.
• Salvar a partitura em PDF (com pauta e furos), o áudio em WAV (com som real de gaita), o projeto em JSON e o MIDI.
• Mudar a velocidade e alternar entre tema claro e escuro.
• Funciona sem internet: as gravações de gaita vêm dentro do app.

PRIVACIDADE
Sem cadastro, sem anúncios e sem rastreamento. Seus arquivos ficam no seu aparelho.

CRÉDITOS

• Áudio: Tone.js (licença MIT).

Full description (EN)
DigitaHinos Gaita is a MIDI visualizer for the 10-hole diatonic harmonica (Richter tuning, key of C). Open a MIDI file or write your own score and see, note by note, which hole to play and whether to blow or draw.

WHAT YOU CAN DO
• Open MIDI files (.mid) and follow the harmonica playing, with the hole lit up and a blow (↑) or draw (↓) arrow.
• See bends (½, 1 and 1½ step), overblows and overdraws when a note needs them.
• Switch the position of a note when it exists on more than one hole.
• Cover C4 to C7, all chromatic notes.
• Compose with up to 8 voices, insert chords and use articulations and ties.
• Save the score as PDF (with staff and holes), the audio as WAV (with real harmonica sound), the project as JSON, and MIDI.
• Change playback speed and switch between light and dark themes.
• Works offline: the harmonica recordings are bundled in the app.

PRIVACY
No sign-up, no ads, no tracking. Your files stay on your device.

CREDITS
• Harmonica recordings: FluidR3_GM soundfont (Frank Wen), CC BY 3.0, via midi-js-soundfonts.
• Audio: Tone.js (MIT license).
• Font: Inter (SIL Open Font License).

O que pode dar problema na revisão

  • Gravações de terceiros (CC BY 3.0). As gravações de gaita vêm do soundfont FluidR3_GM (Frank Wen), conforme o README do projeto, e já estão dentro do app. O crédito está no app, na política e nas descrições; confira a licença no repositório github.com/gleitz/midi-js-soundfonts.
  • Uso da internet. Os sons da gaita já estão embutidos e o app funciona sem internet; no APK a biblioteca Tone.js e a fonte também ficam dentro do app.
  • Botão PIX. Fica escondido no APK. Para mostrar, defina SHOW_PIX=1 no passo "Montar o app" do workflow.
  • E-mail público. A política usa meuidwp@duck.com, o mesmo que já estava no app.
